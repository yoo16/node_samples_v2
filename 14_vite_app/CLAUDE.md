# 🎓 Vite + Hono + SQLite 学習プロジェクト

## 目的

- フロントエンドとバックエンドの分離
- REST API の理解
- SQLite による永続化
- TypeScriptによる型安全設計

---

## 構成

project/
  frontend/  ← Vite
  backend/   ← Hono + SQLite

---

## 前提

- Node.js がインストールされていること
- npm が利用可能であること

---

## 起動方法

npm install
npm run dev

frontend → <http://localhost:5173>  
backend → <http://localhost:3000>

---

## ステップ

1. メモリ配列でAPIを作る
2. SQLiteへ移行
3. CRUDを実装
4. 設計を整理する
